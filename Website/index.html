§ 02

House rules

Reading the page

Every trap is labelled. A red chip marks something designed to fail a naive selector. An amber chip marks a timing hazard. Read the chip, then decide how you'd handle it before you look at the hint.

The activity log at the bottom of the screen records clicks, changes, uploads and frame events. Use it to confirm your script really did what you think it did.

Running your tests

Serve the folder, then point Playwright at it:

node server.js # → http://localhost:4173 npx playwright test

A starter playwright.config.js and a worked example spec ship in this folder. See README.md.
