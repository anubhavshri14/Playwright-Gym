§ 03

Clicks that don't land

Transparent overlay intercepted

A sibling div covers the button. Playwright reports the interceptor by name and retries until it clears.

pointer-events: none

This button receives no pointer events at all. A normal click resolves against whatever is behind it.

§ 06

Canvas and SVG

Canvas no DOM inside

Three targets are painted, not built. There is nothing to locate — click by offset with click({ position: { x, y } }) and read the result text.

SVG className is not a string

SVG children are real DOM nodes, so they are locatable — but element.className returns an SVGAnimatedString, not a string, which breaks naive property checks.
