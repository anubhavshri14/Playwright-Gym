Module 05

Upload & download

Six upload surfaces and six ways to get a file back out. The awkward ones are the invisible input behind a styled button, the drop zone that never renders an <input> at all, and the download link that does not exist until a job finishes.

§ 01

Upload surfaces

Plain inputs
    Hidden input behind a button display:none

    Clicking the button opens the OS picker, which a test cannot drive. Target the input itself with setInputFiles() — it works even though the element is not visible.

      Drop zone no input element

      Accepts DataTransfer only. Build one in page.evaluateHandle and dispatch a drop event.

        § 02

        Upload with progress ~2.4 s

        Pick a file, then start the transfer. The button disables, a progress bar advances, and a success panel replaces it. Assert on the end state, not the bar width.

        § 03

        Downloads

        Wrap each of these in page.waitForEvent('download'). The generated ones never touch the network — the bytes are made in the browser and handed to a temporary object URL that is revoked straight after.

        Files inside a frame
