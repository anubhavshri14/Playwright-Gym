Module 02

Dynamic tables

Virtualised 10k-row boards live in module 10. This room stays on real tables. Five tables that each break a different assumption: rows that renumber when sorted, a page size that changes what nth(3) means, cells that rewrite themselves mid-assertion, a table built from divs, and one with merged cells and a table inside a cell.

§ 05

Grid built from divs no table tags

Same data, zero <table> elements — this is what most component libraries render. Playwright's getByRole('row') still works because the ARIA roles are correct. Columns are also visually reordered by CSS, so DOM order ≠ reading order.
