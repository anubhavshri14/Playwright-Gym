Module 08

Shadow DOM

Playwright pierces open shadow roots on its own, so most of this page is easier than it looks. The two that are genuinely hard: a closed root, which nothing can reach from outside, and component state that lives on the element object with no DOM trace.

What actually changes

Still works: locator(), getByRole, getByTestId, chained locators, and text matching — all cross open shadow boundaries.

Stops working: CSS combinators that span the boundary (div > input where the boundary sits between them), document.querySelector from evaluate, XPath, and anything targeting a closed root.

§ 01

Open roots, three of them

Three instances of the same component. Each has its own shadow tree containing an input with the same test id, so you must scope to the host element first.

§ 02

Roots inside roots 3 boundaries

Host → shadow → host → shadow → host → shadow → the input. A single chained locator still resolves it, which is the point of the exercise: try it with a raw document.querySelector in evaluate and watch it fail.

§ 03

Closed root unreachable

attachShadow({ mode: 'closed' }) keeps no public reference to the root. Locators find the host and stop. The component exposes a public API instead — which is exactly how you should test one: through the interface the component actually offers.

The sealed component

page.getByTestId('sealed-input') → 0 elements.

Its public API
const host = page.locator('gym-sealed'); await host.evaluate(el => el.setCode('OVR-99')); await host.evaluate(el => el.getCode());
§ 04

Slots and parts

Slotted children stay in the light DOM — they are yours, styled by the page, and trivially locatable. ::part() exposes named internals for styling without opening the whole tree.

Exposed parts

The bar exposes part="track" and part="fill". Page CSS can reach them with gym-meter::part(fill); locators reach them anyway, because the root is open.

§ 05

Shadow inside a frame

Frame boundary first, then shadow boundary. frameLocator handles the first; the locator handles the second on its own.

§ 06

Component state on the object

gym-panel exposes a value getter/setter, a reset() method and a history array. None of it is reflected to an attribute. Reach it with evaluate.

const panel = page.locator('gym-panel').first(); await panel.evaluate(el => el.value = 'PRIMARY-01'); await panel.evaluate(el => el.history); await panel.evaluate(el => el.reset());
